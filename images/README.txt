СОХРАНЯЙТЕ ФОТО ТРЕНИРОВОК ЗДЕСЬ.

Как привязать фото к тренировке:
1. Положите файл в эту папку (images). Например: техника.jpg
2. Откройте editor.html, найдите нужную тренировку,
   в поле «Фото» впишите имя файла: техника.jpg
3. Нажмите «Скачать новый schedule.js» и замените им старый
   файл в папке data (имя должно остаться schedule.js).
4. Обновите сайт — F5.

Подойдёт jpg/png/webp. Фото без тренировок лежит здесь безвредно.
Мини-фото появится на карточке, большое — в окне описания.
