Инструкция

Редактор расписания

  1. Правьте поля ниже. День недели — заголовок карточки; у каждой тренировки — название, время, место и описание.
  2. Можно начать не с форм, а с готового файла плана: кнопка «📥 Загрузить файл с планом недели» заполнит формы из TXT-файла (образец — план-недели — шаблон.txt).
  3. Фото тренировки: положите картинку в папку images и впишите её имя в поле «Фото» (например, техника.jpg). Без фото — оставьте поле пустым.
  4. Нажмите «Скачать новый schedule.js» — файл сохранится в «Загрузки».
  5. Переместите скачанный файл в папку data с заменой старого. Имя файла менять нельзя — должно быть schedule.js.
  6. Когда сайт размещён на хостинге: заполните блок «Публикация на сайт» внизу страницы и нажмите «🚀 Опубликовать на сайт» — файл запишется на сервер сам, перемещать ничего не нужно.
  7. Откройте сайт index.html и обновите (F5).

Черновик сохраняется автоматически: если закрыли страницу — кнопка «Вернуть черновик» вернёт правки.

Публикация на сайт

Работает, когда сайт уже размещён на хостинге и на нём установлен файл publish.php с заданным паролем. Локально не публикуется — используйте «Скачать новый schedule.js».
