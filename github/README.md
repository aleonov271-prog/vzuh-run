# ВЖУХ — сайт бегового клуба (vzuh.run)

Исходный код сайта бегового клуба «ВЖУХ» (Москва) — [vzuh.run](https://vzuh.run).

Статический сайт + три интерактивных сервиса на PHP, без фреймворков и сборки.

## Что здесь есть

| Раздел | Что это |
|---|---|
| **Главная** (`index.html`) | Клуб, тренировки недели, контакты. Отзывы посетителей отправляются через `reviews.php` (лимит 3/час/IP, honeypot от спама) |
| **База знаний** (`knowledge.html`, `kb/`) | 21 статья по технике бега: интерактивное дерево с поиском по слову + статические страницы для поисковиков |
| **Редакторы** (`editor.html`, `kb-editor.html`) | Редактирование расписания и базы данных без кода, публикация кнопкой (`publish.php`, `kb.php`), автобэкапы данных |
| **Генератор планов** (`ai-plan/`) | Анкета → план подготовки в Excel. Два способа: через GigaChat API (календарь и объёмы считает **сервер**, модель пишет только содержание дней, затем 20 детерминированных «слоёв сшивки» проверяют её ответ) и через **алгоритм без ИИ** — темповые зоны по формуле Ригеля от недавнего результата, пул сессий по фазе × дистанции; мгновенно, без токенов |

## Архитектурный принцип

Детерминированное — на сервер, вероятностное — модели. Фазы подготовки,
объёмы, пульсовые зоны, лимит частоты — всё считается в `ai-plan/plan.php`
по анкете; LLM (`GigaChat-2` / `-2-Pro`) генерирует тексты тренировок, и
даже если модель «ленивается» или отвечает мусорными кусками, план остаётся
корректным: ровно один длинный бег в неделю, объём сходится, километры
в текстах равны километрам ячеек. Полный список правил — в
`ai-plan/генерация планов — ограничения — сводка.md`.

Альтернативный режим «Алгоритм (без ИИ)» (`model=algo`): план собирается
полностью детерминированно — прогноз времени по формуле Ригеля из недавнего
результата старта (есть в анкете; без него — новичковый трек: словесные темпы
и контрольный тест 5К в первую неделю), зоны E/M/T/I/R, периодизация
база → конструкция → специализация → подводка с общим серверным календарём,
пул сессий по фазе × дистанции, лонг ≤ 35 % недельного объёма. Без GigaChat,
без лимита частоты, генерация мгновенная.

## Структура

```
index.html, knowledge.html, kb/     страницы
css/ js/ images/ assets/           оформление и скрипты
data/                              расписание и база (schedule.js, knowledge.js)
ai-plan/                           сервис генерации планов (plan.php)
tools/                             утилиты (локальный сервер, генератор kb-страниц)
```

## Запуск локально

```
python tools/devserver.py            # статика + форма отзывов
# ai-plan требует PHP: открывать на хостинге с PHP 7.4+
```

## Настройка

- `publish.php`, `kb.php` — пароль публикации задать в константе файла.
- `ai-plan/plan.php` — ключ GigaChat API в файле `secrets.php` (см. ниже).
- Данные (`data/`) редактируются через `editor.html` / `kb-editor.html`.
