# README — Загрузка расписания на неделю

Расписание недели живёт в **одном файле** — `data/schedule.js` (данные сайта
читают его при загрузке страницы). Менять его можно тремя способами;
все три описаны подробно в `расписание — инструкция.md`, здесь — рабочий
минимум.

---

## Способ 1. Редактор — формы без кода (рекомендуется)

1. Открыть **`editor.html`** (двойным щелчком, локально или на сайте).
2. Заполнить поля: **Заголовок дня** (`Понедельник · 5 октября`), для каждой
   тренировки — **Название** (`ВЖУХ-ИНТЕРВЛЫ`), **Время** (`18:00–19:30`),
   **Место** (адрес/точка сбора), **Описание** (открывается по клику на
   тренировку на сайте). Фото необязательно: картинку в папку `images/`,
   в поле «Фото» — имя файла (`техника.jpg`).
3. Кнопки «+ Добавить день» / «+ Добавить тренировку» / «✕ Убрать…».
   День без тренировок — в поле «Текст для дня без тренировок» написать
   `Выходной`.
4. Вверху: **«Подзаголовок»** (строка над неделей) и **«Примечание»**
   (строка под расписанием).
5. Нажать **«Скачать новый schedule.js»** — файл упадёт в «Загрузки»;
   перенести его в папку `data/` с заменой. Имя не менять: должно остаться
   `schedule.js`.
6. Открыть сайт, **Ctrl+F5**.

> Правки автоматически сохраняются как черновик: кнопка
> «Вернуть черновик» вверху редактора вернёт незафиксированное,
> если страницу закрыли.

## Способ 2. Загрузка готового текстового плана (быстрый, для заранее
## подготовленного плана)

1. Скопировать файл **`план-недели — шаблон.txt`**, переименовать
   (например `план-недели 12-18 октября.txt`), заполнить в Блокноте по
   подсказкам внутри (`#`-строки — это объяснения, в план не попадают).
2. Формат в файле:
   - строка подписи сверху: `Подпись: Неделя 12–18 октября. …`;
   - заголовок дня: `ПН · 12 октября` (краткие ПН ВТ СР ЧТ ПТ СБ ВС);
   - строка тренировки: **`время | название | место`** — поля разделены
     вертикальной чертой `|`, время обязательно;
   - описание — строки с отступом (2+ пробела) под строкой тренировки;
     несколько строк склеятся в абзац. Можно не писать вовсе;
   - день без тренировок: `ВЫХ | Выходной`.
3. **Сохранить в UTF-8** (Блокнот: Файл → Сохранить как → кодировка UTF-8).
4. Открыть `editor.html` → **«📥 Загрузить файл с планом недели»** →
   выбрать файл. Редактор покажет сводку: сколько найдено дней и тренировок
   и какие проблемы (нет времени / забыли `|`). Исправить файл, загрузить
   ещё раз.
5. Подтвердить — формы заполнятся, дальше просмотреть глазами и следовать
   способу 1 (шаги 5–6).

## Способ 3. Публикация на сайт, когда он уже на хостинге

1. Открыть `editor.html` (локально или на сайте) и заполнить/загрузить план
   (обычно — способами 1 или 2).
2. Внизу страницы — блок **«Публикация на сайт»**: вписать **адрес сайта**
   (`https://vzuh.run`) и **пароль публикации** — запомнятся,
   второй раз вводить не нужно.
3. Нажать **«🚀 Опубликовать на сайт»** → «Опубликовано ✅» →
   открыть сайт, **Ctrl+F5**.
4. Запасной путь (если сервер недоступен): **«Скачать новый schedule.js»**
   и залить его в `data/` через панель хостинга.

> Перед каждой публикацией прежний `schedule.js` автоматически копируется
> на сервере в `data/_backups/` с датой в имени.

## Что обновлять каждую неделю (чек-лист)

- [ ] Даты в заголовках дней (`Понедельник · 5 октября` …)
- [ ] «Подзаголовок» (номер недели над расписанием)
- [ ] Времена / названия / места / описания
- [ ] «Примечание» (оговорки: погода, старты, изменения)
- [ ] Фото в `images/`, если появились новые

## Если что-то не так (частые случаи)

| Симптом | Что делать |
|---|---|
| Расписание не поменялось | Проверить, что файл реально заменён в `data/` на сервере; **Ctrl+F5** |
| Появилась старая неделя-заглушка | Синтаксическая ошибка в `schedule.js` (запятая/кавычка) — в редакторе «Вернуть черновик» и переопубликовать |
| Фото не показывается | Сверить имя в поле «Фото» с именем файла в `images/` буква-в-букву |
| Окно тренировки пустое | Не заполнено «Описание» — заполнить и опубликовать снова |
| «Ошибка связи с сайтом» при публикации | На хостинге нет `publish.php` (залить в корень) или неверный адрес сайта |
| «Неверный пароль» / «не задан пароль» | Сверить пароль с `publish.php` на хостинге; если там заглушка `ЗАДАЙТЕ-ПАРОЛЬ-ЗДЕСЬ` — заменить настоящим |

Фотографии: маленькими буквами, без пробелов (`техника.jpg`,
`интервалы-2.jpg`).
